# Z-Anatomy
Z-Anatomy app Unity project

# Builds instructions
Requires Unity Hub install and open project with Unity 2020.3.23f1, for android also install de JDK and dependencies (from same unity hub) and set JAVA_HOME in system environment variables. Path of JDK is in Edit > Preferences > External Tools > Android > (first path to OpenJDK)
